# ShopPilot

A multi-store ecommerce platform (a mini Shopify) with AI built into the core:
catalog enrichment, hybrid search, a shopping agent, and a support bot.

> Work in progress. Built day by day. See [docs/progress.md](docs/progress.md).

## Stack
FastAPI · PostgreSQL + pgvector · Redis · Next.js · OpenAI · Docker
